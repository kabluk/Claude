котором суд освобождает от пошлины (125% федерального порога бедности):
- 1 чел. — **$2 660.00** · 2 — **$3 606.67** · 3 — **$4 553.33**

  _При смене ревизии FW-001 обновить таблицу здесь и в feeWaiver.js._

### Таймлайн-вехи (Family Code / CCP)
Проверено 2026-07-13 (leginfo.legislature.ca.gov). Анкор — дата вручения
документов ответчику (service_date):
- **Fam. Code §2339(a)** — развод не может стать окончательным раньше, чем через
  **6 месяцев** от даты вручения summons+petition ответчику ИЛИ его явки (что
  раньше). → веха `waiting_period_end` = service + 6 мес + 1 день.
- **Fam. Code §2104(f)** — предварительная декларация о раскрытии (petitioner)
  подаётся одновременно с петицией или **в течение 60 дней с подачи петиции**. →
  веха `disclosures_due` = filing + 60 дней (fallback на service_date).
- **Code Civ. Proc. §412.20(a)(3)** — у ответчика **30 дней** после вручения на
  подачу ответа (указано на summons FL-110). → веха `response_deadline`.
  Зафиксировано в `src/timeline/milestones.js` (юнит-тест
  `npm run check-milestones`). Тексты вех — фактические, в `t.milestones`
  (UPL-линт покрывает). Планировщик — Supabase pg_cron + Edge Function
  `notify-milestone` (НЕ n8n).

### Право (Business & Professions Code / Rules of Professional Conduct)
Тексты проверены 2026-07-12 (leginfo.legislature.ca.gov):
- **B&P §6402.1** — регистрант LDA обязан иметь: paralegal-сертификат
  (24+ semester units) ЛИБО бакалавриат + 1 год law-related experience под
  надзором лицензированного адвоката. → У основателя гейт **не пройден**.
- **B&P §6400(g)** — LDA прямо запрещено давать "advice, explanation, opinion,
  or recommendation ... selection of forms".
- **B&P §6400(c)(2)** — ограничения на то, кто может быть LDA / как оформлен статус.
- **B&P §6401(b)** — работа для лицензиата State Bar лежит вне LDA-главы
  (основание attorney-review модели).
- Вывод зафиксирован как решение в `docs/DECISIONS.md` (2026-07): основная
  модель — Reviewing Attorney, не LDA.

## KILLED (проверено и отклонено)

- **«LegalZoom не был LDA»** — ОПРОВЕРГНУТО: LegalZoom в итоге зарегистрировался
  как LDA в LA County. «Путь чистого софта» в CA заканчивается регистрацией.
- **«Аренда LDA-номера»** (использовать чужой регистрационный номер) — убита
  B&P §6408 + §6400(c)(2).
- **«Fee-splitting $299 со сплитом на бэкенде»** (единый платёж, потом делёж с
  адвокатом) — убита Rule of Professional Conduct 5.4 (запрет раздела гонорара
  с неадвокатом). Единственный чистый путь — **две раздельные транзакции**
  (реализовано в `ReviewCheckout`, деньги адвоката через нас не проходят).
