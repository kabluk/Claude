## Этап 1 — Продуктовое ядро (приоритет: высокий)

### #3 · EU Allergen Compliance
**Почему важно:** Закон EU 1169/2011 обязывает рестораны маркировать 14 аллергенов. Штраф до €20,000. Ни один конкурент в нашей ценовой нише не делает это красиво.

**Что делаем:**
- Иконки 14 аллергенов (глютен, молоко, орехи, яйца, рыба, соя и др.) на каждое блюдо
- Badge-система: маленькие цветные иконки под описанием блюда
- PDF-экспорт аллергенного листа для проверок (для ресторана)
- "Фильтр по аллергенам" — клиент выбирает свои аллергены, меню показывает только безопасные блюда

**Результат:** Menvio = единственный дешёвый сервис с legal-ready EU compliance.

---

### #5 · Живое меню — Sold Out в реальном времени
**Почему важно:** Клиент заказывает блюдо которого нет — скандал, плохой отзыв. Простая фича с огромной ценностью.

**Что делаем:**
- Кнопка "Sold Out" в admin-панели ресторана (простой пароль-доступ)
- Блюдо зачёркивается + серое у всех клиентов в реальном времени
- Восстанавливается одним нажатием
- Опционально: авто-сброс в полночь

**Реализация:** Firebase Realtime DB или даже просто URL-параметр с JSON (serverless).

## Этап 2 — Рост и удержание

### #6 · Авто-перевод на 20 языков
**Почему важно:** Турзоны Барселоны, Рима, Парижа — меню читают немцы, китайцы, американцы. Ресторан платит €299/мес конкурентам за это. Мы даём за $29.

**Что делаем:**
- Определение языка браузера (`navigator.language`) — авто-переключение
- Ручной переключатель языка (флаги вверху)
- Claude API для перевода при создании меню (один раз, хранится)
- Приоритет языков: EN, ES, DE, FR, IT, RU, ZH, JA, AR, PT, NL, PL, UK, KO, TR, SV, DA, NO, FI, CS

**Важно:** Перевод делается ОДИН РАЗ при создании меню, не при каждом открытии — дёшево и быстро.

---

### #8 · Аналитика сканирований
**Почему важно:** Рестораны не знают что работает. Кто зашёл, что смотрел — золото для маркетинга.

**Что делаем:**
- Количество уникальных сканирований QR (по IP/UA)
- Самые просматриваемые блюда (клик-трекинг по карточкам)
- Пик активности по времени (завтрак/обед/ужин)
- Конверсия: сканировал → добавил в корзину → отправил заказ
- Dashboard для ресторана: простая страница, еженедельный email-отчёт

**Реализация:** Простой serverless endpoint (Cloudflare Workers) + Supabase/PlanetScale.

---

### #4 · "Done for You" — White Glove Setup
**Почему важно:** Ресторан не хочет разбираться с SaaS. Он хочет готовый результат.

**Модель сервиса:**
- **Starter $29/мес** — шаблон, сам настраивает
- **Pro $69/мес** — мы строим меню за 48 часов, первое фото AI включено
- **Concierge $99/мес** — мы строим, обновляем ежемесячно, аллергены, перевод на 3 языка, аналитика

**Что делаем технически:**
- Intake-форма для нового клиента (Google Form или Tally)
- Стандартный процесс: форма → меню готово за 48ч → ссылка клиенту
- AI фото через kie.ai API для каждого блюда

## Этап 3 — Конкурентный ров

### #10 · Стратегия "Предпостроенного демо"
**Теория:** Приходишь не с презентацией, а с готовым продуктом.

**Процесс:**
1. Находим ресторан через Google Maps (4+ звёзды, нет QR-меню или некрасивое)
2. Парсим их меню с сайта/Yelp/Google
3. Строим красивый демо за 2 часа (как Dragon Garden LA)
4. Пишем: *"Мы сделали QR-меню для вашего ресторана — посмотрите демо. $49/мес чтобы активировать."*

**Цель:** 50 предпостроенных демо в месяц → конверсия 15-20% → 8-10 новых клиентов.

**Что делаем технически:**
- Скрипт-парсер меню с Yelp/Google (Python/Node)
- Авто-генерация HTML из шаблона по JSON с меню
- База демо-меню (Airtable или Notion)

---

### #13 · Интеграция платежей (Stripe / Revolut Pay)
**Почему важно:** Sunday (QR-оплата) привлёк $100M инвестиций на этой идее. Мы можем добавить это как опцию.

**Что делаем:**
- Stripe Payment Link встроен в корзину (альтернатива WhatsApp для тех кто хочет онлайн-оплату)
- Revolut Pay для EU (популярен в Европе)
- Модель: **мы НЕ берём комиссию** — ресторан напрямую подключает свой Stripe аккаунт
- Это принципиальный дифференциатор от всех конкурентов

---

### #15 · Мониторинг цен конкурентов
**Почему важно:** Уникальная фича, аналогов нет в нише $29-99.

**Что делаем:**
- Ресторан указывает 2-3 конкурента (название или адрес)
- Наш crawler сканирует их онлайн-меню / Yelp / Google Food раз в неделю
- Email-алерт: *"Burger Palace снизил цену на чизбургер с $15 до $13"*
- Dashboard: сравнение цен по категориям

**Реализация:** Playwright/Puppeteer scraper + Claude API для извлечения структуры меню.
