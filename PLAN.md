# Califormis — план работ (источник правды по порядку)

**Правила работы (обязательны для любой сессии и для ассистента):**
1. Делаем строго по фазам сверху вниз. Не начинаем фазу N+1, пока не закрыты
   все «ворота» (gate) фазы N.
2. Перед каждой задачей ассистент сверяется с этим файлом. Если просьба
   относится к более поздней фазе — ассистент СНАЧАЛА предупреждает
   («это Фаза X, мы ещё в Фазе Y»), и только с согласия пользователя делает.
3. SEO-индексация — последняя и актуальна ТОЛЬКО после деплоя (нет сайта —
   нечего индексировать). Вопросы `noindex`/robots/sitemap решаем при деплое
   в Фазе 5.
4. Любое отклонение от плана фиксируется здесь же (раздел «Изменения плана»).

Статус: ✅ готово · 🚧 в работе · ⏳ не начато
