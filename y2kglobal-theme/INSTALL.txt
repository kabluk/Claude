===========================
Y2K GLOBAL — УСТАНОВКА ТЕМЫ
===========================

ТРЕБОВАНИЯ
----------
- WordPress 6.0+
- WooCommerce 8.0+
- Родительская тема: Storefront (официальная тема WooCommerce)

ШАГ 1 — УСТАНОВИТЬ STOREFRONT
------------------------------
WordPress Admin → Внешний вид → Темы → Добавить → поиск "Storefront" → Установить (НЕ активировать)

ШАГ 2 — ЗАГРУЗИТЬ ДОЧЕРНЮЮ ТЕМУ
---------------------------------
WordPress Admin → Внешний вид → Темы → Добавить → Загрузить тему → выбрать файл y2kglobal-theme.zip → Установить → Активировать

ШАГ 3 — ОБЯЗАТЕЛЬНЫЕ ПЛАГИНЫ
------------------------------
1. Judge.me Reviews — бесплатные отзывы с фото
   https://wordpress.org/plugins/judgeme-woocommerce-reviews/

2. WP Rocket (платный) или LiteSpeed Cache (бесплатный) — кэш и скорость

3. Smush или ShortPixel — сжатие изображений

ШАГ 4 — НАСТРОЙКИ
------------------
WordPress Admin → Внешний вид → Настроить → "Y2K Global Settings":
- Загрузить Hero Image (главное фото на главной)
- Текст заголовка hero
- Текст кнопки hero
- Код скидки для попапа (по умолчанию: WELCOME10)
- Текст сроков доставки

ШАГ 5 — СТРАНИЦЫ (создаются автоматически при активации)
---------------------------------------------------------
- /about         — О нас
- /faq           — FAQ
- /shipping-returns — Доставка и возврат

Проверь: WordPress Admin → Страницы → убедись что они созданы и опубликованы.

ШАГ 6 — МЕНЮ
-------------
WordPress Admin → Внешний вид → Меню:
Создай меню "Primary" с категориями магазина и назначь его на "Primary Menu".
Рекомендуемая структура:
- Новинки (ссылка на /product-category/new-arrivals)
- Топы
- Низ
- Платья
- Аксессуары
- Распродажа

ШАГ 7 — POPUP ИЗОБРАЖЕНИЕ
--------------------------
Загрузи изображение модели в:
wp-content/themes/y2kglobal-theme/assets/images/popup-model.jpg
(Рекомендуемый размер: 400x500px)

ШАГ 8 — MAILCHIMP (опционально)
--------------------------------
Для автоматической подписки через попап:
WordPress Admin → Инструменты → Настройки Y2K:
- Добавь Mailchimp API Key
- Добавь Mailchimp List/Audience ID

Список подписчиков без Mailchimp сохраняется в:
WordPress Admin → Инструменты → Экспорт опций (ищи y2k_email_subscribers)
