# BUILD SPEC · detnav.com

Задание для Claude Code. Первая сборка.
Референсы рядом: `detnav-pages.html` (вёрстка), `detnav-intake.html` (опрос),
`INTAKE-universal.md` (обоснование вопросов), `JOURNEY.md` (тексты маршрута).

---

# 1 · Что строим

Статический многоязычный сайт помощи людям, задержанным ICE, и их близким.
Три языка равноправны: **en · es · ru**.

**Ограничения, не подлежащие обсуждению:**
- аккаунтов нет · оплаты нет · аналитики нет вообще
- персональные данные на сервер не уходят никогда
- весь текст в `content/`, ни строки копирайта в компонентах
- n8n не используется

# 2 · Стек

```
Vite + React + TypeScript + Tailwind
vite-react-ssg     пререндер всех страниц в статику
vite-plugin-pwa    офлайн только для страницы «документы»
```

# 4 · Опрос · ядро продукта

**22 вопроса, один набор для всех.** Персон в интерфейсе нет.
Ветвление по обстоятельствам, не по типу человека.

Блоки: рамка · опознание · связи · залог · зависимые · здоровье ·
что рассыплется · документы · Зона Б.

**Полностью в браузере.** Ответы никуда не отправляются, состояние в памяти,
PDF собирается клиентом.

## Две зоны

**Зона А** — логистика и доказательства. Ответ порождает задачу.
**Зона Б** — год и способ въезда, прошлые дела, приказы, судимости.
Ответы **не выводятся на экран и не дают выводов**, попадают только в PDF.
Не сегментировать по юридическому профилю — это практика права.

## Задачи

Каждая задача: заголовок · строка сути · раскрытие с блоками
`Зачем · Как · Что сказать · Форма · Внимание` · строка «почему в списке».

**Пометка «доказательство»** — у задач, выведенных из перечня факторов
Matter of Guerra. Обязательна поясняющая карточка внизу списка.

**У каждого вопроса обязательна подсказка.** Не пересказ вопроса, а что человек
от ответа получит. Аудитория включает людей с низкой грамотностью и в состоянии
паники; вопрос без объяснения либо пропускают, либо отвечают наугад.
Там, где есть вариант «не знаю», под ответами — строка о том, что это
нормальный ответ и он тоже даёт задачу.

**Право на слушание о залоге оспаривается.** С июля 2025 власти считают, что
вошедшие без проверки подлежат обязательному задержанию без залога; апелляционные
округа разошлись, Пятый округ (Техас, Луизиана, Миссисипи) поддержал позицию
властей, ожидается Верховный суд. Задача «выяснить, будет ли слушание» стоит
**перед** задачами про обязателя. Нигде не утверждать, относится ли это
к конкретному человеку. На всех страницах про залог — дата актуальности.

**Границы шаблонов:** бытовая переписка — можно писать целиком
(письмо арендодателю, записка в школу, разговор с обязателем).
Юридические инструменты — только ссылка на официальную форму, без образцов
(доверенность, аффидавит об опеке, форма доступа к медданным, любое письмо судье).

## Сборка и отправка пакета

Через сервер файлы не проходят. Схема целиком — в `DOCS-AND-FIXES.md`, кратко:

- сжатие **при добавлении фото**, не при сборке: длинная сторона 1600 px,
  JPEG 0.7, по одному файлу за раз
- хранение в IndexedDB, после отправки предложить удалить
- титульный лист: дата, номер версии, оглавление по факторам,
  **список того, чего не хватает**, ответы Зоны Б отдельным блоком
- отправка: системное «Поделиться» → скачать → печать. Поле адреса
  получателя не заполняем
- больше 20 МБ — резать на части с общим оглавлением
- имя файла без имени человека

# 4.5 · Главная страница

Референс: `detnav-landing.html`.

Два этажа на одном экране, входа и стены нет.

**Первый экран:** заголовок, живая демонстрация, кнопка «Начать».
Демонстрация — это **не фоновое видео и не сток**. Это цикл из трёх сценариев
на CSS и JS: появляется вопрос → подсвечивается ответ → вырастает задача
со строкой «почему в списке». Весит килобайты, объясняет продукт без чтения.
Уважает `prefers-reduced-motion`.

**Кнопка «Прослушать эту страницу»** — `SpeechSynthesis`, на языке страницы.
Обязательна: значительная часть аудитории читает плохо. Нулевой трафик.

**Ниже по скроллу:** три шага · блок про данные · цены · чего мы не делаем.

Блок про данные крупно и в зелёной рамке: ответы, фотографии и список остаются
в телефоне, на сервер не уходят. Формулировка «нам нечего потерять, нечего
продать и нечего выдать по запросу» — оставить.

Цены показываем, хотя платного нет: бесплатное перечислено подробно,
платное коротко и помечено «готовим».

```css
--red:#E4382B; --yellow:#F2C230; --green:#37A05A; --blue:#5B8FB0;
```

# 7 · Линтеры · блокирующие шаги CI

`lint-upl.mjs` — сканирует `content/**`, падает при совпадении.

```
ru: вы имеете право · вам следует · ваш лучший вариант · в вашем случае
    ваши шансы · мы рекомендуем · вам подходит · вам положено
    дорого · дёшево · выгодно · лучший адвокат · гарантируем
es: usted tiene derecho · usted debe · su mejor opción · en su caso
    sus posibilidades · recomendamos · le conviene · usted califica
    caro · barato · garantizamos · el mejor abogado
en: you have the right · you should · your best option · in your case
    your chances · we recommend · you qualify · you are eligible
    cheap · expensive · guarantee · best attorney
```

Исключение только явное, с причиной:
`<!-- upl-ok: прямая речь пользователя, не наша рекомендация -->`

`lint-minimize.mjs` — запрещает поля `name` `address` `dob` `status` `a_number`
вне справочников.

Оба ставятся **до написания контента**.

# 8 · Объём первой сборки

**Страницы:** home · 5 экранов первой ночи · journey · attorney · sponsor ·
bond-pay · deadlines · 3 служебные. Каждая ×3 языка.

**Опрос:** полный, 22 вопроса, в браузере.

**Функциональность:** больше ничего. Ни форм, ни сервера, ни состояния между сессиями.
Поиск по локатору — исходящая ссылка.

**Готово, когда:**
- все страницы отдаются готовым HTML *(проверить `curl`)*
- оба линтера зелёные
- Lighthouse производительность и доступность > 90
- `hreflang` и `sitemap.xml` корректны
- нет сетевых запросов, кроме шрифтов
- статические страницы читаются при выключенном JavaScript

# 9 · netlify.toml

```toml
[build]
  command = "npm run build"
  publish = "dist"

[[headers]]
  for = "/*"
  [headers.values]
    X-Frame-Options = "DENY"
    X-Content-Type-Options = "nosniff"
    Referrer-Policy = "no-referrer"
    Permissions-Policy = "geolocation=(), camera=(), microphone=()"
    Content-Security-Policy = "default-src 'self'; font-src 'self' fonts.gstatic.com; style-src 'self' 'unsafe-inline' fonts.googleapis.com; img-src 'self' data:"
```

`no-referrer` принципиально: переход на сайт ICE не должен сообщать,
откуда пришёл человек.
