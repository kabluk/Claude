## Аудит безопасности (22.08.2026, сессия 2, D-032)

Скилл — это инструкции, попадающие в контекст агента с доступом к репо и
секретам, поэтому проверялось всё содержимое, а не выборочно:

1. **Скрытые Unicode-символы** (zero-width, bidi-переопределения, tag-блок,
   управляющие) — скан по кодовым точкам всех 10 файлов апстрима: чисто.
   Не-ASCII только типографика: × – →.
2. **Сеть и исполнение** — ни одного curl/fetch/wget/eval/exec; единственный
   URL — `http://localhost:3000` в примере шаблона. Единственный исполняемый
   файл — hitl-loop.template.sh: интерактивный read/printf без сети и eval,
   прочитан построчно.
3. **Инъекции в промпт** — нет ни «ignore previous instructions», ни просьб
   читать env/секреты/креды, ни адресов для «отчётности». Обратное:
   diagnosing-bugs содержит раздел Redact, ТРЕБУЮЩИЙ вымарывать секреты из
   любого показываемого вывода — оставлен как есть.
4. **Каждый файл прочитан человеко-читаемо целиком** (362 строки суммарно)
   до копирования.

## Обновление

Апстрим обновляется руками: скачать нужный файл, продиффать с нашей копией,
повторить аудит по чек-листу выше, перенести правки, обновить хеш коммита
здесь. Автообновлений нет намеренно (vendoring).
