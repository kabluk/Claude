## Порядок запуска

1. **Сборка запуска:** `PUBLIC_LAUNCH=1 npm run build` — включает
   индексацию (robots.txt Allow, без X-Robots-Tag noindex, sitemap
   с detnav.com). Обычная сборка остаётся превью-режимом (noindex).
2. **Домен:** Netlify → Domain management → Add custom domain →
   detnav.com. Netlify покажет свои неймсерверы (dns1–4.p0X.nsone.net).
3. **GoDaddy:** Nameservers → Change → вписать неймсерверы Netlify.
   Пропагация до 24 часов. SSL-сертификат Netlify выпустит сам.
4. **Деплой launch-сборки** (zip или git-подключение).
5. **Проверка после запуска:** https://detnav.com/ru/ открывается,
   редирект языков работает, `curl -I https://detnav.com/robots.txt`
   отдаёт Allow, сертификат валиден.
6. **Дистрибуция** — канал из этапа 2 скилла: приход/организация,
   пять семей, build in public. Не открывать всем сразу: drip
   по 10–20 приглашений (soft launch из этапа 6).

## После запуска — не забыть

- Git-подключение Netlify к ветке вместо ручных zip (авто-деплой),
  переменная окружения PUBLIC_LAUNCH=1 в настройках сборки Netlify.
- Мониторинг: соft-launch когорта, activation (дошёл до списка задач),
  фидбек — без аналитики на сайте, руками через разговоры (правило №1).
- Страница «Пути освобождения» (habeas) — теперь можно делать:
  черновик формулировок в задаче о залоге, показать адвокату.
