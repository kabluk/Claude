# Что строим

`detnav.com` — статический многоязычный сайт помощи людям, задержанным
иммиграционной службой США, и их близким. Три языка равноправны: **en · es · ru**.
Испанский — основной рынок, не перевод вдогонку.

Аудитория: жена, у которой ночью забрали мужа, открыла ссылку из WhatsApp
на дешёвом телефоне. Человек, который готовится заранее. Часть аудитории
читает плохо и боится любых институтов.

# Семь правил, которые не обсуждаются

1. **Аккаунтов нет. Оплаты нет. Аналитики нет** — ни Google, ни Plausible, никакой.
2. **Персональные данные на сервер не уходят никогда.** Опрос, фотографии,
   список задач, сборка PDF — всё в браузере.
3. **Весь текст живёт в `content/`.** Ни строки копирайта в компонентах,
   иначе линтер его не увидит.
4. **Тексты не переписывать.** Формулировки выверены под запрет на практику
   права без лицензии. Менять — только по явной просьбе, с проверкой линтером.
5. **Пререндер обязателен.** Пять страниц первой ночи — органическая воронка,
   клиентский рендер её не соберёт.
6. **n8n не использовать** ни в каком виде.
7. **Ничего не публиковать** до проверки юристом и носителем испанского.
   Строить, деплоить на превью — можно. Открывать `detnav.com` — нет.

# Две зоны опроса · главное про UPL

**Зона А** — логистика и доказательства. Ответ порождает задачу. Всё видно на экране.

**Зона Б** — год и способ въезда, прошлые дела, приказы, судимости.
Ответы **не выводятся на экран и не производят никаких выводов**.
Попадают только в PDF для адвоката.

Не сегментировать по юридическому профилю. Не строить ветвления вида
«10+ лет → такая-то форма защиты». Это практика права.

Шаблоны: бытовая переписка пишется целиком. Юридические инструменты —
только объяснение и ссылка на официальный бланк, без образцов.

# Критерии готовности

- все страницы отдаются готовым HTML — проверить `curl`
- оба линтера зелёные
- Lighthouse: производительность и доступность выше 90
- `hreflang` и `sitemap.xml` корректны
- ни одного сетевого запроса, кроме шрифтов
- статические страницы читаются при выключенном JavaScript
- кнопка «Прослушать» работает на трёх языках
- `prefers-reduced-motion` уважается

# Чего не делать

Аналитику · формы, собирающие что-либо · `localStorage` для чего-либо,
кроме языка · сторонние домены, кроме Google Fonts · текст внутри компонентов ·
оставшиеся девять шагов маршрута — они помечены «готовим» ·
таймер, PDF, мониторинг, оплату, остальные штаты.
