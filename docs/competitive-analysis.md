# Конкурентный анализ (research с источниками, 2026)

Живой research (fan-out поиск + адверсариальная верификация 3 голосами). Даты/цены —
снимок на 2026, вендорские данные (маркетинг), не аудит. Проверенных источников: 22.

## Главный вывод
**Hello Divorce — сильнейшая прямая угроза** (California-native): флэт-тарифы,
встроенный CA-калькулятор алиментов, прозрачный attorney-upsell, глубокое
сопровождение через 6-мес waiting period + attorney judgment-review.

## Две наши гипотезы ОПРОВЕРГНУТЫ
1. ❌ «Ни у кого нет калькулятора» — **неверно.** DivorceWriter ($137 flat) встраивает
   CA guideline-калькулятор прямо в интервью. Hello Divorce тоже имеет.
2. ❌ «Все бросают после PDF» — **неверно для Hello Divorce** (ведёт весь путь:
   service → FL-115 → 60-дн disclosures → FL-180 judgment).

## Дыры, которые ВЫЖИЛИ (реальные рвы)
1. 🟢 **Испаноязычный процесс заполнения — нет ни у кого** (только переведённые
   маркетинг-страницы). Самый чистый ров.
2. 🟢 **Глубина 58 округов CA (обязательные local forms)** — отраслевая дыра; вендоры
   рекламируют «county-specific», но реальная генерация локальных cover sheets не доказана.
   (напр. Santa Clara FM-серия, LA cover sheets)
3. 🟡 **Калькулятор уровня настоящего §4055/DissoMaster** (таймшер+налоги) — ни у кого
   не доказан. Дифференциация по точности, а не наличию.

## Что обязательно перенять (силы конкурентов)
