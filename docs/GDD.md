# PHOTO FIGHTERS — Game Design Document
**Version:** 0.1 (Prototype)  
**Genre:** Mobile 2D Fighting  
**Platforms:** iOS, Android (HTML5 prototype)  
**Target Audience:** 16–30, social media users, TikTok

---

## 1. VISION

> "Любая фотография становится бойцом. Кидаешь фото друга, президента, кота — и дерёшься этим персонажем."

Вирусная мобильная файтинг-игра, где игрок загружает фото любого человека (себя, друга, знаменитости) и получает уникального бойца. Контент генерируется пользователями и расшаривается в TikTok автоматически.

**Elevator pitch:** *"Photo Dojo meets Street Fighter meets TikTok"*

## 3. CHARACTER CREATION SYSTEM

### 3.1 Фото → Персонаж

**Фаза 1 (MVP — спрайт оверлей):**
- Face detection (MediaPipe / face-api.js)
- Лицо с фото накладывается на заготовленное тело
- Цвет волос, тон кожи, очки, борода → автоматически подбираются детали

**Фаза 2 (AI генерация):**
- Prompt: `"fighting game sprite, [detected features], [style] fighter, pixel art"`
- Stable Diffusion с ControlNet для сохранения позы
- Уникальный спрайт-лист за 20–40 сек генерации

**Фаза 3 (Viral):**
- Генерация не только спрайта, но и backstory бойца
- Уникальные реплики перед боем на основе лица

### 3.2 Вопросы при создании

После загрузки фото — 2 вопроса:

**Q1: "Как дерётся [имя]?"**
- 🥊 Боксёр
- 🥷 Ниндзя  
- 🤼 Борец
- 🦵 Каратист
- 😤 Уличный

**Q2 (опционально): "Какой он по характеру?"**
- 🔥 Агрессор (атака × 1.2, защита × 0.8)
- 🛡️ Защитник (атака × 0.8, защита × 1.4)
- ⚡ Спринтер (скорость × 1.5, HP × 0.85)

## 4. FIGHTING STYLES — Детальное описание

### 🥊 БОКСЁР
- **HP:** 110  **Атака:** ×1.3  **Скорость:** ×0.8
- **Приёмы:** Jab (быстрый), Cross (мощный), Hook (широкий), Uppercut (анти-прыжок)
- **Спецудар (SP полный):** Fury Combo — 6 быстрых ударов, последний сбивает с ног
- **Механика:** Chip damage при блоке увеличен. Headguard — первый knockdown стоит на ногах.
- **Слабость:** Медленный, плохо работает против дистанционных атак

### 🥷 НИНДЗЯ
- **HP:** 85  **Атака:** ×0.8  **Скорость:** ×1.6
- **Приёмы:** Quick Strike, Spinning Kick, Shuriken (снаряд), Backstep Counter
- **Спецудар:** Shadow Dash — телепорт за спину противника + удар
- **Механика:** После 3 ударов подряд — бонус к следующему удару ×1.5 (combo system)
- **Слабость:** Низкий HP, слабая защита

### 🦵 КАРАТИСТ
- **HP:** 100  **Атака:** ×1.0  **Скорость:** ×1.1
- **Приёмы:** Punch, Round Kick (длинная дистанция), Axe Kick (сверху), Knee Strike
- **Спецудар:** Dragon Kick — летящий удар ногой через весь экран
- **Механика:** Parry window — точный тайминг блока даёт контратаку бесплатно
- **Слабость:** Не лучший в ближнем бою

### 🤼 БОРЕЦ
- **HP:** 130  **Атака:** ×1.5  **Скорость:** ×0.65
- **Приёмы:** Grab (захват, если вплотную), Shoulder Charge, Suplex, Body Slam
- **Спецудар:** Bear Hug — непрерываемый захват, снимает 35 HP
- **Механика:** Grab игнорирует блок. После Knockdown противник получает +20% урона 5 сек.
- **Слабость:** Очень медленный, слаб против дальних атак

### 😤 УЛИЧНЫЙ
- **HP:** 95  **Атака:** ×1.1  **Скорость:** ×1.1
- **Приёмы:** Headbutt, Eye Poke (ослепляет на 1 сек), Low Kick (нельзя заблокировать стоя), Bottle Throw
- **Спецудар:** Dirty Move — случайный из 5 мощных грязных приёмов
- **Механика:** 20% шанс, что атака противника случайно промахнётся (dirty luck)
- **Слабость:** Непредсказуем, в том числе для себя

## 5. MECHANICS

### 5.1 Управление (мобиль)
```
Виртуальный джойстик (левый палец) → движение + прыжок
Кнопки действий (правый палец):
  [P] — лёгкий удар
  [K] — удар ногой  
  [🔥] — тяжёлый удар
  [🛡] — блок (держать)
  [SP] — спецудар (активен когда шкала полна)
```

**Свайп-комбо (дополнительно):**
- Свайп вперёд + P = rushing punch
- Свайп вниз + K = sweep kick
- Двойной тап = dash

### 5.2 Управление (клавиатура, прототип)
| | Игрок 1 | Игрок 2 |
|---|---|---|
| Движение | WASD | Стрелки |
| Удар | J | Numpad 1 |
| Нога | K | Numpad 2 |
| Спец | L | Numpad 3 |
| Блок | X | Numpad 0 |

### 5.3 Боевая система

**Frame data:**
| Атака | Startup | Active | Recovery |
|-------|---------|--------|----------|
| Лёгкий удар | 4f | 4f | 6f |
| Тяжёлый удар | 8f | 6f | 12f |
| Нога | 6f | 6f | 10f |
| Спецудар | 10f | 8f | 20f |

**SP Meter:**
- Заполняется при нанесении и получении урона
- Полная шкала → спецудар
- После использования сбрасывается в 0

**Combo System:**
- 2+ ударов подряд без ответного урона = комбо
- Комбо × multiplier на последний удар
- Combo breaker: если HP < 30%, раз в раунд можно разорвать комбо

**Rounds:**
- Best of 3 раундов по 99 секунд
- Победа: HP противника = 0 (KO) или больше HP по истечении времени (Judge Decision)
- При ничье: Sudden Death — у обоих по 30 HP, первый удар решает

## 6. PROGRESSION & METAGAME

### MVP (нет прогрессии)
- Каждый бой самодостаточен
- Персонажи живут пока открыто приложение

### Фаза 2
- **Fighter Card** — каждый созданный боец сохраняется в коллекцию
- **Rating** — ELO система для онлайн-матчей
- **Streaks** — победы подряд дают бонусные анимации (flame effect, etc.)

### Фаза 3
- **Tournaments** — 8 бойцов, bracket, зрители
- **League of Legends mode** — публичные персонажи vs публичные

## 7. VIRAL MECHANICS

### Автошеринг
- По окончании боя: кнопка **"Поделиться в TikTok"**
- Видео: [фото оригинал → трансформация → бой → победитель] ~15 сек
- Watermark: "Photo Fighters — скачай и подерись"

### Challenge mechanic
- Игрок создаёт бойца → получает **challenge link**
- Отправляет другу → тот загружает своё фото → **автоматический матч**
- Результат присылается обоим

### Celebrity battles
- Предустановленные знаменитые бойцы (политики, спортсмены, персонажи)
- "Победи [имя]" — встроенный challenge
- Обновляются еженедельно (актуальные инфоповоды)

### Creator mode
- Стримеры могут дать зрителям ссылку → зрители загружают фото → бой в реальном времени
- Overlay для OBS

## 9. ТЕХНИЧЕСКИЙ СТЕК

### MVP / Прототип
```
Frontend:  HTML5 Canvas + Vanilla JS
Physics:   Custom (простая аркадная физика)
Face crop: Canvas API (без AI, умный crop)
Input:     Keyboard (web), Touch (mobile)
```

### Production (Mobile)
```
Game Engine:    Unity 2022 (2D)
AI Backend:     Python + FastAPI
Face Detection: MediaPipe Face Mesh
Sprite Gen:     Stable Diffusion + ControlNet
Backend:        AWS Lambda + S3
Auth:           Firebase
Multiplayer:    Photon PUN2 (реалтайм) / Socket.io
Analytics:      Amplitude
```

### Архитектура генерации персонажа
```
[Фото] → MediaPipe → [Face landmarks]
                           ↓
                    Feature extraction:
                    - возраст (приблиз.)
                    - пол
                    - аксессуары (очки, борода)
                    - выражение
                           ↓
              [Выбор стиля пользователем]
                           ↓
              SD Prompt builder:
              "2D fighting game character sprite,
               [features], [style], white background,
               game asset, 8 poses"
                           ↓
              Stable Diffusion API (RunPod)
                           ↓
              [Sprite sheet] → Unity → Игра
```

## 12. RISKS & MITIGATIONS

| Риск | Вероятность | Митигация |
|------|-------------|-----------|
| AI генерация медленная (>30с) | Высокая | Показываем лицо на базовом теле сразу, потом заменяем |
| Модерация (неприемлемые фото) | Высокая | Pre-moderation API + user reporting |
| Celebrity likeness права | Средняя | Только публичные деятели + disclaimer |
| Техдолг (разные лица → артефакты) | Средняя | Face swap fallback на MVP |
| Конкурент скопирует | Средняя | Скорость + сетевой эффект (коллекции бойцов) |
