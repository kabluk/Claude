## Ключевые связки (единый источник данных)
- **Калькулятор алиментов** → FL-150 (п.5,16) **и** FL-342 → числа совпали без расхождений
  (доход 7,200/9,500, таймшер 65/35, страховка $180).
- **FL-142** (имущество) → FL-150 summary (11a/b/c) **и** FL-345 (раздел) → суммы совпали
  (активы 467,400, долги 11,700).
- **FL-345 equalization** посчитан приложением до доллара: Maria платит Carlos $213,650 →
  у обоих ровно $227,850.
- Дети (Sofia/Diego) едины на FL-105/FL-150/FL-180/FL-341/FL-342.
- FL-180 (п.4j/k/l/m) корректно ссылается на приложения FL-341/342/343/345.
- FL-141 (waiver финального раскрытия) ↔ FL-144 согласованы.

## Что подаётся в суд, а что служится
- **Служится супругу (НЕ в суд):** FL-140, FL-142, FL-150.
- **В суд из раскрытия идёт только:** FL-141 (доказательство вручения) + FL-144 (при waiver).

## Чек-лист проверки формы (7 пунктов)
Форма «готова» только когда все пройдены. Смотреть **на десктопе**, не на телефоне.
1. **Полнота:** SET N, MISSING 0, SKIPPED 0 + read-back совпал.
2. **Чекбоксы по факту** (ловушка §2 residency — не отмечать обе стороны без основания).
3. **Формат дат:** MM/DD/YYYY, не ISO.
4. **Деньги/числа:** разделители ($450,000); вычисляемые итоги верны.
5. **Нет наездов** текста на печатные подписи (флэттен/десктоп).
6. **Стороны/роли** не перепутаны; имена едины во всём пакете.
7. **Актуальность ревизии** сверена; записана в FormTemplate.

Правило: где есть подпись «под страхом лжесвидетельства» — пп.2 и 6 критичны.

## Типовые баги, пойманные при проверке (для регресса)
- FL-100: §1 «We are married» не ставилась; §2 обе residency; §10b наезд; даты ISO; сумма без запятой.
- FL-105: период проживания склеен в одну ячейку (From «дата – present»).
- Шапка-адрес: нужно хранить структурно (street/city/state/zip/phone/email), а не строкой.
- FL-150: сначала пустая внутри (маппилась только шапка) — generic-имена полей.
- FL-180: §4l spousal, §4i дети, §3a jurisdiction не заполнялись.
- Внутренние имена AcroForm часто вводят в заблуждение (поле «Email» = «Attorney For»,
  «DateofHearing» = «pages attached») — сверять по подписи, не по имени.

## Авто-проверка ревизий (реализовать)
Скрипт «обнови формы»: для каждой формы в `public/forms/` скачать текущую с
courts.ca.gov (egress открыт), сравнить строку ревизии внизу PDF с нашей + FormTemplate,
вывести таблицу «форма | наша | актуальная | статус». Устаревшие — перекачать, обновить
FormTemplate, предупредить о перепроверке маппинга. Повесить на расписание (раз в месяц).
