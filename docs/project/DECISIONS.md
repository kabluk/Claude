# DECISIONS

- D-001 (2026-08-15): Репозиторий выделен из kabluk/Claude через subtree
  split. Причина: три проекта в одном репо путали ветки/CI/кроны.
  Последствие: крон переезжает в main этого репо; старый воркфлоу в
  kabluk/Claude подлежит удалению после первого зелёного прогона здесь.
- D-002 (2026-08-15): Охват v1 — «каталог-первый» (не мониторинг-первый,
  не лид-фиды-первые). Причина: индексация — самый длинный таймер
  (6–12 мес), дельта-движок нужен в любом варианте, остальные ветки
  остаются открытыми. Выбор сделан из трёх вариантов, см.
  kabluk/Claude docs/roadmap.html §04.
- D-003 (2026-08-15): Стек — Cloudflare Workers + D1 + R2, Astro SSR.
  Причина: 2,2 млн страниц статикой не собрать; у владельца уже есть
  CF-аккаунт и опыт деплоя (detnav); D1 хранит срез для рендера,
  полная история — в release-ассетах/R2.
- D-004 (2026-08-15): UX/UI владеет frontend-engineer (по правилу
  project-orchestrator: молчание = «дизайн не делает никто»).
- D-005 (2026-08-15): Юридические рамки продукта (из разбора в
  kabluk/Claude docs/moat-analysis.html и чата 14.08): только данные
  уровня компаний (никаких водительских историй — 49 USC 31150/FCRA);
  запрет employment-скрининга в ToS; собственные метрики маркируются
  как свои, не как «рейтинг FMCSA»; дисклеймер 49 USC 31150 на
  entity-страницах; бизнес-контакты с opt-out; в лид-фидах пометка
  типа телефона (TCPA — ответственность звонящего, но помогаем
  комплаенсу).
- D-006 (2026-08-15): Имя CarrierRadar, домен carrierradar.com (свободен,
  RDAP). Покупка — за владельцем; до покупки ORIGIN — плейсхолдер
  одной константой.
