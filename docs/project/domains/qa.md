  шаг. Оговорка: axe-core автоматически ловит только часть критериев WCAG (по
  индустриальным оценкам — около трети), ручная проверка нужна отдельно и в бэклоге
  пока не заведена.

  через `file://`, из-за чего CSS не грузился и контраст тривиально «проходил» на
  неокрашенном HTML. Найдено 2026-08-06 при независимой проверке новой страницы
  через настоящий HTTP-сервер; тот же реальный баг контраста (`text-slate-400`,
  245 узлов на `/agencies/`) сидел на уже «проверенных» страницах. Скрипт исправлен
  (`node:http` вместо `file://`), баг исправлен (`text-slate-500`), перепроверено —
  подробности в D-014. Урок: зелёный прогон одним и тем же инструментом — не
  доказательство; независимая перепроверка другим путём — доказательство.
