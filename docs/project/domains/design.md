# Design — источник правды дизайн-системы AccessAtlas

Обновлено: 2026-08-07 (итерация CN-TOKENS + CN-HERO, D-063).
Направляющий документ — `docs/project/DESIGN_CONSTITUTION.md` (§3, §24–29, §37–38, §57).
Реализация токенов — `src/styles.css` (`@theme`), это единственное место, где
значения живут в коде; здесь — их назначение и правила использования.

North star (§3): принципы Linear/Stripe/Vercel — точность, сдержанность,
иерархия, engineering feel. Принципы, не копирование стиля.

## 1. Палитра

### Нейтральная база

Шкала **slate** Tailwind v4 — холодный серый со сдвигом оттенка к синему
(hue ≈ 257 в oklch), НЕ чистый серый. Осознанно взята готовой, а не
переопределена: значения годами калиброваны по контрасту, и весь существующий
UI уже на ней — переопределение дало бы риск контраста без видимой пользы.

| Роль | Класс | Hex | Использование |
|---|---|---|---|
| Основной текст | `--color-ink` (slate-800) | `#1e293b` | body text, 14.6:1 на белом |
| Вторичный текст | slate-600 | `#475569` | lede, подписи, футер (7.6:1) |
| Третичный текст | slate-500 | `#64748b` | метаданные, только ≥14px (4.8:1) |
| Границы | slate-200 / slate-300 | `#e2e8f0` / `#cbd5e1` | карточки / поля форм |
| Подложки | slate-50 / slate-100 | `#f8fafc` / `#f1f5f9` | trust-блоки, футер / чипы |
| Фон страницы | white | `#ffffff` | body |

Правило: текст slate-400 и светлее — запрещён (контраст < 3:1).

### Акцент — один, сдержанный

Индиго. Роль: **интерактив, бренд, evidence** (кнопки, ссылки-CTA, логотип-глиф,
бейджи верифицированных сертификатов, featured-ring). Severity НЕ красится
акцентом — см. ниже.

| Токен | Hex | Контраст | Использование |
|---|---|---|---|
| `--color-accent` | `#4338ca` | 7.9:1 на белом | кнопки, ссылки, фокус-кольцо |
| `--color-accent-strong` | `#3730a3` | 9.9:1 (белый текст) | hover/active |
| `--color-accent-soft` | `#eef2ff` | — (фон) | подложка chip-accent |
| `--color-accent-border` | `#c7d2fe` | — (граница) | граница chip-accent |

Почему индиго: уже был в проекте (преемственность всех прошлых axe-прогонов);
холодный, той же температуры, что slate-база; дистанцирован и от «неонового
accessibility-зелёного» (§57 прямо запрещает), и от красно-оранжевой зоны,
которая целиком отдана severity.

### Severity — семантическая шкала сканера

Согласована 1:1 со шкалой impact axe-core (`scanner.ts`:
critical/serious/moderate/minor) + success/info (§27). Каждая тройка
text/soft/border: текст ≥ 4.5:1 и на белом, и на своей подложке (проверено
скриптом и живым axe-прогоном).

| Severity | Text | Soft bg | Border | Контраст на soft |
|---|---|---|---|---|
| Critical | `#b91c1c` | `#fef2f2` | `#fecaca` | 5.9:1 |
| Serious | `#9a3412` | `#fff7ed` | `#fed7aa` | 6.9:1 |
| Moderate | `#854d0e` | `#fffbeb` | `#fde68a` | 6.6:1 |
| Minor | `#334155` | `#f1f5f9` | `#e2e8f0` | 9.5:1 |
| Success | `#166534` | `#f0fdf4` | `#bbf7d0` | 6.8:1 |
| Info | `#4338ca` | `#eef2ff` | `#c7d2fe` | 7.1:1 |

Правила:
- **Цвет никогда не единственный носитель смысла** (§27): рядом с severity
  всегда текстовая метка (`impactLabel`). Иконки не добавлялись — метка уже
  есть, дублирующая иконка без функции = декорация (§29).
- Critical и Serious — разные оттенки (красный/оранжевый), не один красный
  двух насыщенностей: различимо при большинстве форм дальтонизма, плюс метка.
- Ошибки форм — `--color-critical` + `role="alert"` + `font-medium`.
- Success — только заработанное состояние (чистый скан), не украшение.
- Info/акцент совпадают намеренно: «информация» в этом продукте — это
  интерактивная подсказка, отдельный шестой цвет умножал бы палитру без смысла.

## 2. Типографика

- **Гротеск: Inter Variable**, self-hosted через `@fontsource-variable/inter`
  (импорт в `main.tsx`, woff2 внутри бандла — CDN нет, CSP чистый). Inter —
  в списке рекомендованных конституцией (§25); уже был в проекте.
- **Моно-компаньон: системный стек** `ui-monospace, SFMono-Regular, Menlo,
  Consolas, Liberation Mono, monospace` (`--font-mono`) — для кода, селекторов
  в отчёте, `code` в гайдах. Кастомный моно-шрифт сознательно НЕ введён:
  моно-текста в UI мало (селекторы находок, инлайн-код), платить сотни КБ
  и candidate-LCP за него — против перфоманс-бюджета. Пересмотреть, если
  появится библиотека компонентов (CN-COMPONENTS) с большими код-блоками.
- **`tabular-nums` для всех чисел-метрик** (§25): класс `.num` — score отчёта,
  счётчики instances, stat-ряд главной, счётчики каталога, футер. Правило:
  число, которое сравнивают или которое меняется, — всегда `.num`.
- Иерархия — весом и отступом, не размножением кеглей: `.h1` (30/36px bold),
  `.h2` (20px semibold), body 16px, метаданные 12–14px. Новые кегли не
  заводить без записи здесь.

## 3. Spacing и форма

- Ритм — сетка Tailwind 4px; секции главной разделены `mt-10`/`mt-12`
  (§26: щедро между секциями, плотно внутри компонента).
- Контент-колонка `max-w-5xl` (`container-page`); текстовые блоки —
  `max-w-2xl` (короткие строки для объяснений, §25).
- Радиусы: поля/кнопки `rounded-lg` (8px), карточки/панели `rounded-xl`
  (12px), чипы `rounded-full`. Других радиусов нет.
- Тени: только `hover:shadow-sm` на карточках. Больших теней нет — глубина
  через границы (§24 quiet & precise).
- Карточки ≤ 3 колонок на десктопе (§26: без card walls).

## 4. Фокус и интерактив

- Глобальное фокус-кольцо: `:focus-visible { outline: 2px solid
  var(--color-accent); outline-offset: 2px }` — на ВСЁМ, всегда видимо.
  `outline-none`/`focus:outline-none` запрещены (последние два вхождения
  сняты этой итерацией — LeadForm, ScanPage).
- Поля форм — единый класс `.input` (граница slate-300 → slate-500 при
  фокусе поверх кольца).
- Кнопки: `.btn` (акцент, hover = `--color-accent-strong` — смена цвета, не
  прозрачности: opacity-hover роняет контраст ниже 4.5 на светлом фоне);
  `.btn-ghost` (вторичная). Ссылки в тексте — underline, не только цвет.
- Один акцентный элемент на поверхность: в шапке это «Scan» (первый пункт
  навигации) + CTA-кнопка справа; внутри секции — одна `.btn`.

## 5. Severity-семантика в UI (карта применения)

- `ReportPage` findings: `chip chip-{impact}` — единственное место, где
  красный/оранжевый допустимы как фон-подложка.
- Legal-basis блок отчёта: amber (family = moderate) — информация о праве,
  не severity; без сумм штрафов (D-035).
- Empty/success-состояния (§37): объясняют и ведут дальше (чистый скан →
  ссылка на methodology; отчёт не найден → «run a new scan»). Тупиков нет.
- Ошибки (§38): спокойные, конкретные, с путём вперёд (`scanErrorMessage`).

## 6. Чего НЕ делаем (§57 + D-035, гейты)

- Градиенты, glassmorphism, неоновый «accessibility-зелёный», блобы, 3D,
  декоративный motion, автоплей.
- Fear-копия и суммы штрафов — нигде (гейт `no-fine-amounts.test.mjs`).
  Прежний заголовок главной «…before the deadline finds you» снят этой
  итерацией именно поэтому.
- Выдуманные счётчики: «sites scanned today» из §7 НЕ показывается — механизм
  агрегата в D1 не построен; появится счётчик — появится и блок.
- Второй акцентный цвет, «брендовые» перекраски severity, иконки-декорации,
  смешение икон-стилей (иконок сейчас ноль — до выбора одной системы, §29).
- Тёмная тема: НЕ реализуем, пока не готовы держать контраст и фокус на том
  же уровне в обеих (§28: опциональна, качество важнее моды).
- CDN-ресурсы любого рода (шрифты, скрипты) — self-host only (CSP, D-063).

## 7. Верификация дизайна

Контраст палитры — не обещание, а гейт: `npm run audit-a11y` (axe, 26 страниц,
включая главную с hero и формы) обязан быть 0 нарушений; при изменении
палитры чинится палитра, не проверка. Скрипт-проверка контраста пар токенов —
в D-063 (одноразовая, значения выше в таблицах). Скриншоты итерации:
scratchpad `design/before-*.png` / `after-*.png` (2026-08-07).
