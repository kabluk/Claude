## Правовой контекст в отчёте — 2026-08-06 (D-032, D-033)

`ReportPage` показывает блок «Legal basis» под находкой об отсутствующем/неполном
заявлении о доступности. Две части, разные по природе:

1. **Данные из API** (`ScanFinding.jurisdictionNote`, ставит воркер) — конкретный
   закон юрисдикции. Сумма штрафа попадает в текст только если сверена с
   первоисточником (сейчас — только DE). До D-032 поле возвращалось API, но
   фронтенд про него не знал и молча ронял — фича была невидима две итерации.
2. **Константа в UI** (не данные из API) — факт гармонизации: требования едины
   по ЕС (EN 301 549), надзор — нет. Одинаков для всех юрисдикций, тащить через
   воркер незачем.

Формулировка сверена с текстом Directive (EU) 2019/882, не с пересказом: «одного
окна» как в GDPR ст. 56 в EAA нет, по ст. 21/23 каждая страна назначает свои
органы и проверяет услуги на своей территории. Владелец сознательно выбрал одну
честную строку вместо перечня применимых законов по каждому рынку — перечень из
12 статей читается как запугивание при нулевой доп. точности (находка та же),
R1. Контраст (amber-800 на amber-50) проверен разовым прогоном axe-core:
0 нарушений `color-contrast`; `/report/:id` в постоянный CI-аудит не входит —
требует id.

Селектор страны на `/scan` (D-032): по умолчанию «Detect from the domain» —
прежнее поведение, выбирать не обязательно. Подсказка честно называет
ограничение: выбор одной страны задаёт, о какой отчитаться, а не единственную
применимую.

## Подпись бейджа теперь зависит от декларанта (2026-08-06, D-042)

`certLabel()` принимает сам бейдж, а не его `kind`: одна подпись на оба случая
скрывала различие, ради которого задача и заводилась. Три формы:
«Named auditor in a **public-sector** accessibility statement» (81 запись),
«…in a **private organisation's** accessibility statement» (13),
«…in a **published** accessibility statement» (2, декларант не установлен).
Фасет в `FilterableList` остался один («Named in a statement») — фильтр
отвечает на «названы ли вообще», сектор виден в подписи на карточке.
На `/bfsg-check/` у каждой ссылки-доказательства появился маркер
«(öffentliche Stelle)» / «(privates Unternehmen)» — читатель немецкой страницы
видит, кто именно назвал прюфера, до того как откроет документ.
`statementEvidence()` вернул тип: `{url, declarant}[]` вместо `string[]`.
