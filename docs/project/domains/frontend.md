## Предстоит (Фаза 1) — с явными UX-приёмочными критериями (VISION.md, D-011)

- `/scan` лендинг: объяснение приватности, честный прогноз времени скана.
- Асинхронный прогресс скана (не спиннер — «страница 2 из 6»), Browser Rendering
  может занять 10–30+ секунд на 6 страниц.
- `/report/:id`: находки по WCAG-критериям, severity, impact score, шаринг по ссылке.
  Отчёты — noindex, приватная ссылка. Понятные, не технические состояния ошибки
  (сайт недоступен / заблокировал бота / скан завис) — каждое своё, не одно общее.
- Блок «подходящие агентства» под отчётом + доверие в UI каталога: бейджи верификации
  и ссылки-доказательства на карточке (данные `sourceRefs`/`lastVerified` уже есть,
  UI ещё не спроектирован).
- Оценка стоимости — эвристика × price bands, с дисклеймером.
