# Конкурентный разбор — живые фетчи, 2026-08-13

Метод: WebFetch + WebSearch (все ниже страницы отвечали живьём, не из памяти модели).
Firecrawl-fallback **не использован** (0 кредитов) — все нужные страницы либо
открылись через WebFetch, либо (при 404) найдены через WebSearch и дофетчены.
Каждый пункт помечен: **[FETCH]** — подтверждено живым запросом страницы,
**[SEARCH]** — из результатов веб-поиска (не полный фетч страницы),
**[NOT FOUND]** — страница не открылась, ничего не придумано взамен.

Позиции по ключевикам — по вводным владельца, не перепроверялись.

## 1. accessibleweb.com — главный объект (аналог по размеру, но ранжируется)

**Бесплатные инструменты (поимённо + URL), [FETCH] с главной:**
- Website Accessibility Checker — `/website-accessibility-checker/`
- WCAG Color Contrast Checker — `/color-contrast-checker/`
- Accessibility Statement Generator — `/accessibility-statement-generator/`
- WCAG Knowledge Base — `/web-accessibility-knowledge-base/`
- Chrome-расширение "Accessible Web Helper"

**Contrast checker [FETCH]** `/color-contrast-checker/`: hex-ввод + color picker
("eyedropper"), матрица AA/AAA (обычный/крупный текст/UI-компоненты),
превью текста 14pt/18pt, кнопка Reverse Foreground/Background, интеграция
с их Chrome-расширением для проверки контраста прямо на живой странице.
Без логина.

**`/rating/aa/` [FETCH]**: это программатик-SEO, но **малого масштаба** — только
3 сиблинг-страницы (Level A / AA / AAA conformance), не большой куст. Каждая
страница — образовательный лендинг про уровень WCAG с 13 ссылками на success
criteria + CTA на чекер и контактную форму. Доп. поиск `site:accessibleweb.com/rating/`
[SEARCH] не нашёл индексированных страниц сверх этого — подтверждает малый масштаб.

**`/question-answer/` [FETCH+SEARCH]**: это программатик Q&A-хаб (шаблонные
страницы ~1500 слов, институциональный автор "Accessible Web", блок "Newest
Questions" внизу, множественные CTA на RAMP trial). Точное число страниц не
установлено (сайт-индекс не вскрылся через site:-поиск), но паттерн
подтверждён на 2+ примерах (`/question-answer/how-can-i-make-my-powerpoint-presentations...`,
`/question-answer/are-running-headers-in-a-pdf-accessible/`). Форма подачи
нового вопроса — `/ask-a-question/` [FETCH] — **требует email** (и CAPTCHA);
сам архив вопросов читается свободно, гейт только на подаче нового вопроса.

**`/tips-tools-tutorials/` [FETCH]**: контент-хаб — 105 постов в этой категории,
90 в Webinar Archive, 85 в Video Library, 14 тем в таксономии, 11+ страниц
пагинации. Вебинары, гостевые интервью, туториалы от новичковых до продвинутых.

**Что продают [FETCH]** (`/`, `/pricing/`): платформа **RAMP** —
Starter $49/мес (1 сайт, 1000 сканов), Advanced $99/мес, Pro $299/мес,
Pro+ $599/мес (легал-саппорт), $10 за доп. 1000 сканов, 14-дневный триал без
карты. Плюс услуги: WCAG-аудит, VPAT, тестирование с реальными
пользователями AT, Accessible Web Academy (курсы от $20).

**Момент запроса email/денег [FETCH]**: `/website-accessibility-checker/` —
**email обязателен** для генерации отчёта (плюс лимит 5 сканов/день на IP);
сами статичные инструменты (contrast checker, statement generator) — без
email. RAMP-триал — email + регистрация аккаунта.

**Что уникального притягивает**: не сам чекер (базовый), а огромный объём
educational/programmatic контента (105+150+ страниц) вокруг него + понятная
тарифная лестница SaaS с триалом без карты.

## 2. accessibilitychecker.org — #1 по «website accessibility checker»

**[SEARCH+FETCH]** Свободный скан: до **2 URL в день бесплатно** (по данным
поиска — точный текстовый источник страницы `/documentation/free-web-accessibility-scans/`
редиректнул на Help Center [FETCH] `help.accessibilitychecker.org/.../products-services-we-offer`,
где детали лимитов не раскрыты текстом статьи).

**Бесплатные инструменты [FETCH]**: "ACE™ Scanner" (базовый, бесплатный),
Color Contrast Checker, Accessibility Statement Generator.

**Платное [FETCH]** `/pricing/`: Lite $69/мес (25 URL), Starter $119/мес
(100 URL, "recommended"), Growth $249/мес (500 URL), Tailored — кастом
(2000+ страниц); при месячной оплате дороже (Lite $89 и т.д.). 7-дневный
триал (без доступа к manual-check и деталям failing elements). Доп. услуги:
ремедиация (проектная), monitoring add-on, VPAT/ACR, PDF/документы, видео-
субтитры.

**Точный механизм обрезки бесплатного скана НЕ подтверждён живым фетчем** —
страница с деталями (`/free-scan/`, `/how-it-works/`) отдала 404, а Help
Center статья не раскрывает конкретных цифр. Не выдумываю цифры.

**Что уникального**: единая понятная сетка тарифов по числу URL (типично для
SaaS-чекеров) + широкий продуктовый ряд (аудит, VPAT, PDF, видео) под одним
брендом.

## 3. webaim.org — почему canonical для contrast checker

**[FETCH]** `/resources/contrastchecker/`: hex-ввод (+ alpha), color picker,
**lightness slider**, eyedropper; вывод — ratio + AA/AAA статус (обычный/
крупный текст); превью текста; **link contrast checker** отдельно (для ссылок,
различимых только цветом); **bookmarklet**; **JSON API** через `&api` в
пермалинке; рекомендация использовать WAVE для проверки всей страницы разом.
Без логина, без рекламы.

**[FETCH]** `/` — прочие инструменты: **WAVE** (полноценный сканер страницы),
**Ask AIMee** (AI-чатбот по доступности), WCAG 2 Checklist.

**Чем берут, не будучи выше по фичам [FETCH]**: WebAIM — программа при Utah
State University, не пытается продавать SaaS-подписку с ростом MRR; монетизация —
через **тренинги, консалтинг и evaluation-услуги**, сам инструмент —
общественное благо с 20+ лет истории и максимальным доверием/beklinks в
отрасли (это и есть их "уникальное" — авторитет и nofollow-независимый
трафик, а не фичи). Пытаться обогнать их фичами бессмысленно — обгонять
нужно нишевой функциональностью и UX, которых у общественного инструмента
нет причин добавлять (см. раздел про coolors/colourcontrast ниже).

## 4. accessibe.com — воронка «бесплатный чекер → продажа» (accessScan)

**[FETCH]** `/accessscan`: вход — URL + email. Результат — "seconds"-скан,
статус accessible/barriers exist, отчёт на "eleven items" по WCAG 2.2 AA
(навигация/меню/карусели, структура контента, графика, формы, таблицы,
читаемость), отчёт **высылается на email** ("Download free report" в inbox).

**Давление на покупку [FETCH]**: явная legal-urgency риторика — "Digital
accessibility lawsuits are on the rise", "Start closing accessibility gaps
in as little as 48 hours", упоминания demand letters/litigation support.
Апселл — экосистема **accessWidget** (оверлей-ремедиация), accessFlow (для
разработчиков), экспертные аудиты. Цены на самой странице скана не
показаны — только через отдельные продуктовые страницы/демо.

**Вывод для нас**: воронку "email → скан за секунды → страх судебного иска →
оверлей" **не копируем** — она прямо противоречит нашей анти-оверлей позиции
(BACKLOG A3-CRON, growth.md). Но полезный урок формата: моментальная
обратная связь (без ожидания очереди) — это то, что клиенты ценят, и это
как раз то, где у нас площадка для настоящего преимущества через честный
сканер с очередью и понятным SLA, а не страх.

## 6. coolors.co / colourcontrast.cc — непрофильные, но обходят вендоров

**coolors.co/contrast-checker [FETCH]**: color selectors, ratio, AA/AAA;
Pro-фичи за подпиской — **Check Palette Contrast**, просмотр вариаций цвета;
глубокая интеграция с генератором палитр/визуализатором coolors (основной
продукт). Не требует логина для базовой проверки.

**colourcontrast.cc [FETCH]**: RGB-слайдеры + HSL-ввод, live-ratio, 4 статуса
(Pass AA/AAA Large/Normal) сразу, кнопка Reverse colours, **сохранение
цветовых схем**, **выбор Google Font** для превью текста, skip-links (сам
инструмент accessibility-first по UX), Chrome-расширение.

**Почему обходят профильных a11y-вендоров в топе выдачи** — вывод из фичей,
не измерение позиций: минималистичный **single-page real-time** UX без
переходов и без гейтов, мгновенная обратная связь на каждое движение
слайдера, глубокая утилитарность для дизайнеров (не юристов/комплаенс-
менеджеров) — они оптимизированы под запрос "проверить два цвета сейчас",
а не под лидогенерацию. Прямой урок для нашей будущей страницы: скорость
и отсутствие трения важнее глубины комплаенс-контента для этого конкретного
интента.

## Минимальная планка фич для нашего contrast checker

По трём топовым (webaim #1, accessibleweb #5, coolors #2 — плюс colourcontrast
как эталон UX):

- Hex/RGB/HSL ввод + color picker/eyedropper (все три).
- Lightness slider для подбора ближайшего проходного цвета (webaim — уникально).
- Live-ratio без клика "Проверить" (coolors, colourcontrast).
- Матрица AA/AAA × обычный/крупный текст/UI-компоненты (все три).
- Превью реального текста в обоих размерах (все три).
- Кнопка Reverse fg/bg (accessibleweb, colourcontrast).
- Пермалинк на конкретную пару цветов + JSON API через параметр (webaim —
  уникальная фича, нигде больше не встретилась).
- Проверка контраста ссылок, различимых только цветом (webaim — уникально).
- Сохранение цветовых схем / история (colourcontrast, coolors Pro).
- Выбор шрифта превью (colourcontrast — уникально, приятная деталь для
  дизайнеров).
- Никакого email/логина на базовом функционале — у всех топовых бесплатно.

**Где можно превзойти**: ни у одного нет одновременно (а) permalink+API
webaim-уровня И (б) real-time UX coolors-уровня И (в) привязки к нашему
каталогу законов/юрисдикций (например "для сайта госоргана в стране X нужен
AA+EN 301 549" рядом с результатом). Это и есть ниша — контекст закона
поверх голого ratio, которого нет ни у одного из шести.

## Что у них есть vs что есть у нас

**Чего у изученных конкурентов НЕТ, что есть у AccessAtlas**:
- Каталог 270 проверенных агентств с источниками — ни у одного из шести нет
  публичного проверенного каталога подрядчиков (у accessibleweb/audioeye/
  accessibe — они сами подрядчик, а не маркетплейс/каталог).
- Явное покрытие 13 юрисдикций + EN 301 549 рядом с инструментом (у всех
  контекст права привязан к продажам услуг, не к бесплатному инструменту).
- Явно заявленная анти-оверлей позиция как выбор бренда (accessibe/audioeye
  сами и есть overlay-вендоры).

**Чего у нас пока нет, что есть у них** (честно): готовый сканер с очередью
ещё не публичен как у accessibilitychecker.org/accessibleweb (у них это
рабочий продукт годами); объём образовательного контента (100+ страниц)
как у accessibleweb; институциональный авторитет уровня webaim.org.

## Вывод: что копировать как отраслевой стандарт

1. Живой real-time contrast checker без клика "Submit" и без логина/email на
   базовом функционале (стандарт у всех шести).
2. Матрица AA/AAA для обычного/крупного текста/UI-компонентов + превью
   реального текста — минимальный набор, ниже которого нет смысла выходить.
3. Permalink/шаринг результата (webaim) — дёшево в реализации, ожидаемо
   пользователем.
4. Понятная лестница тарифов по числу URL/сканов (accessibilitychecker.org,
   accessibleweb RAMP) — если делаем платный тариф на сканер.
5. Content-hub вокруг инструмента (accessibleweb tips-tools-tutorials) —
   но без надобности копировать масштаб 100+ страниц сразу.

## Вывод: где наше уникальное преимущество

1. Каталог 270 проверенных агентств с источниками — этого нет ни у кого
   из шести живых конкурентов буквально.
2. Юрисдикции 13 стран + EN 301 549 как контекст поверх голого
   инструмента (ratio/скан) — у конкурентов право продаётся отдельно от
   бесплатных тулов, у нас может быть встроено прямо в результат.
3. Явная анти-оверлей позиция — у части топ-игроков (accessibe, audioeye)
   это структурный конфликт интересов, который мы можем прямо
   противопоставить в контенте вокруг чекера.
