# VISION — AccessAtlas

Обновлено: 2026-08-05

## Проблема

С 28.06.2025 действует European Accessibility Act (в DE — BFSG, во FR — RGAA-обязательства,
в US — ADA/Section 508). Компании обязаны делать сайты доступными, но не понимают:
что именно у них сломано, сколько стоит починить и кому это поручить. Спрос замерен:
≈45 000 запросов/мес по 8 рынкам, CPC до $86, и **ни одного каталога в топ-10 выдачи** —
только сами вендоры (см. `docs/deepdive-accessibility-directory.md`).

## Пользователи

1. **Обязанная компания** (e-commerce, SaaS, банки, паблишеры ЕС/US): «нам письмо/дедлайн/иск —
   что делать и кто сделает?»
2. **Агентство аудита доступности**: хочет квалифицированные лиды и видимость.
3. Позже: **compliance-менеджер** внутри компании — постоянный мониторинг соответствия.

## Продуктовая модель: 4 слоя (не «каталог»)

Принятая эволюция продукта (см. DECISIONS D-003):

```
Directory → Decision Engine → Lead Marketplace → Vertical SaaS
```

1. **Directory** — каталог проверенных исполнителей: агентства, аудиторы, юристы,
   инструменты. Страна × стандарт × услуга, доказуемый источник у каждой записи. ✅ построен.
2. **Decision Engine** — бесплатный сканер + подбор исполнителя по отрасли, стране,
   стеку, бюджету и срокам.
3. **Lead Marketplace** — единая RFQ-форма, заявка сразу нескольким исполнителям,
   отслеживание ответов.
4. **Vertical SaaS** — чек-листы соответствия, управление аудитами, хранение отчётов,
   напоминания о повторных проверках, compliance-дашборд.

## Целевая воронка пользователя

```
Scan Website → Accessibility Report → AI объясняет каждую проблему
→ Оценка стоимости исправления → Сравнение агентств (каталог)
→ Booking агентства (RFQ) → Track progress → Re-scan → Compliance Dashboard
```

Каждый шаг воронки монетизируем и углубляет удержание: продукт перестаёт быть списком
компаний и становится частью рабочего процесса клиента — это и есть AI-защищённость
(LLM может назвать Deque, но не может вести верифицированный каталог, маршрутизировать
лиды и хранить историю сканов клиента).

## Ценность / отличие

- Уникальные данные: 99 агентств из обязательных деклараций доступности гос-сайтов ЕС —
  их нет ни в одном каталоге.
- Доказуемость: каждая запись несёт `sourceRefs` + `lastVerified`; ничего не выдумано.
- Static-first: почти нулевые издержки, полный контроль SEO.
- Позиция «настоящий аудит vs оверлей» — репутационно сильная в a11y-сообществе.

## Границы (что НЕ делаем)

- Не делаем автоматическую «сертификацию соответствия» — сканер даёт находки и оценку,
  а не юридическое заключение (дисклеймер обязателен).
- Не продвигаем overlay-виджеты и не берём их в партнёрки.
- Не строим БД для чтения каталога — источник истины остаётся в `data/a11y/*.json`.
- ES/IT — вторая волна; старт EN (+DE/FR-гайды уже есть).

## Успех

- Фаза 0: каталог задеплоен и индексируется без thin-content риска.
- Фаза 1: сканер даёт ≥N сканов/нед, конверсия скан → просмотр каталога.
- Фаза 2: MRR ≈ €2 200 к месяцу 9 (30 лидов/мес + 15 featured + 2 спонсора — модель из deepdive §5).
- Фаза 3: первые подписки на мониторинг (re-scan + дашборд).
