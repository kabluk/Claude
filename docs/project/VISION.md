# VISION — CarrierRadar

**Рабочее имя:** CarrierRadar. **Домен:** carrierradar.com — свободен по RDAP
(проверено 15.08.2026), покупка за владельцем. Тёзок в отрасли нет; ближайшие
по звучанию CarrierSource/Carrier411 — различимы. Имя централизуется одной
константой конфига (SITE_NAME/ORIGIN) с первого дня.

## Проблема
Реестр FMCSA — единственный источник правды о ~2,2 млн активных перевозчиков
США, но state-of-the-art доступа к нему: гос-сайт SAFER с UX девяностых,
пейволлы от $100/мес (BrokerSnapshot) до enterprise (Highway), токсичный
Carrier411. Малый брокер (1–10 человек) и владелец-оператор остаются без
современного инструмента в диапазоне до $100.

## Пользователи
1. Перевозчик / владелец-оператор — проверить свой статус, страховку, профиль
   глазами брокера. Монетизация: аффилиат (факторинг $250–500/клиент,
   страховка CPC $53–66, топливные карты ~$100/активация).
2. Малый брокер / шиппер — веттинг контрагента, мониторинг, алерты.
   Монетизация: подписка $49–79/мес (щель подтверждена конкурентной картой).
3. Страховой агент / факторинг — фиды новых MC-authority. Монетизация:
   лид-листы (бенчмарк CarrierIQ $79–149/мес/штат).

## Ценность и отличие
Публичный слой — сам продукт, не приманка (у конкурентов наоборот).
Исторический слой (ежедневные снапшоты с 14.08.2026) + честный
инцидент-слой (право ответа, срок давности — анти-Carrier411) + цена
$49–79. Полный разбор конкурентов и моатов: kabluk/Claude
docs/moat-analysis.html.

## Границы v1 (решение D-002)
Каталог-первый: entity-страницы + гео-хабы + phone-лукап + дельта-движок.
Личные кабинеты, платежи, инциденты — вне v1.
