## Фаза 1 — Decision Engine (сканер)

Цель: воронка Scan → Report → AI-пояснения → Оценка стоимости → Сравнение агентств.

Критерии выхода:
- [ ] `POST /api/scan` (Browser Rendering + axe-core) сохраняет отчёт в D1
- [ ] `/report/:id`: находки по WCAG-критериям, severity, impact score, шаринг по ссылке
- [ ] AI-пояснения (Claude Haiku, KV-кэш по ruleId×locale) для каждого типа находки
- [ ] Оценка стоимости (эвристика × taxonomies price bands) с дисклеймером
- [ ] Блок «подходящие агентства» под отчётом (страна×стандарт×услуга) с CTA
- [ ] Лендинг сканера со ссылкой из шапки каталога
