трогает только `<tbody>`, кнопка в `<thead>` не пересоздаётся. Демо —

Самый простой компонент библиотеки — единственная реальная ловушка паттерна

конструктивной невозможности). Label — `aria-labelledby` на соседний `<span>`,
не `<label>`-обёртка — чтобы не расширять кликабельную область на текст
подписи незаметно. Демо — два переключателя, стартующих в разных состояниях
(оба визуальных состояния видны статично, `INTERACT`-хук не понадобился).

кастомные select-компоненты. Демо — реальные 7 стандартов каталога из
