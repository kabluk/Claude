## Предыдущее (2026-08-09, A1-REPORT-DIRECT-LINK закрыт: Pages Function для /report/:id / D-103)

Найдена платформенная особенность Cloudflare Pages (не в документации):
`env.ASSETS.fetch()` на путь с `.html` внутри Function получает пустой
редирект-ответ (Pages сам убирает `.html` из URL) — обойдено запросом без
расширения.

правильным шеллом, реальный скан → 200, обычные страницы/настоящий 404 не
задеты. **Не подтверждено**: монтирование React в браузере — Playwright не
может выйти в интернет из этой песочницы (тот же барьер, что у Turnstile
в A1-LANDING). Владельцу стоит один раз открыть реальный отчёт в браузере
