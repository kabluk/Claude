# Task Profiler

Оцени задачу:

$ARGUMENTS

Верни только:

```text
Сложность: 0–5
Риск ошибки: низкий | средний | высокий
Ожидаемый контекст: малый | средний | большой
Рекомендуемая модель: Haiku | Sonnet | Opus
Команда: /model <model>
Причина: 1–2 коротких предложения
Можно упростить задачу: да/нет — как именно
```

Правила:

- Haiku: поиск, rename, форматирование, небольшие локальные исправления, простые объяснения.
- Sonnet: обычная разработка, отладка, тесты, изменения в нескольких связанных файлах.
- Opus: архитектура, сложный root-cause анализ, безопасность, широкие рефакторинги, критические миграции.
- Размер промпта сам по себе не означает сложность.
- Учитывай цену ошибки, количество доменов, необходимость исследования и неоднозначность.
- Не утверждай, что знаешь текущую модель сессии.
