# Task Loop

Узел: $ARGUMENTS

1. Найди узел в `docs/project/GRAPH.yaml`.
2. Проверь зависимости и `approval_required`.
3. Прочитай только входы, интерфейсы, решения и файлы в `scope`.
4. Не расширяй scope молча.

Выполняй цикл:

```text
PLAN → IMPLEMENT → VERIFY → DIAGNOSE → FIX
```

Успех: все команды `verify` прошли и критерии выполнены. Если часть `verify` объективно
недостижима в текущей среде (нет доступа к внешнему аккаунту/сервису, платный ресурс не
включён) — не выдавай это за успех. Пройди всё, что можно проверить локально/живьём, честно
опиши непроверенный остаток и переведи узел в `review`, не в `done`.

Эскалация:
- превышен `max_attempts`;
- две попытки дают ту же ошибку без прогресса;
- требуется архитектурное решение;
- нужно выйти за scope;
- нужен breaking API change;
- обнаружен security-critical риск;
- требуется человеческое одобрение.

Запрещены бесконечные циклы, скрытие failing tests, ослабление тестов ради зелёного результата и production/destructive действия без разрешения.

Обновляй attempts и статусы. При успехе обнови STATUS.md, BACKLOG.md, HANDOFF.md, профильный domains-файл и разблокируй зависимые узлы.

Верни компактный RESULT/TASK/ATTEMPTS/CHANGED/VALIDATION/DECISIONS/RISKS/NEXT.

Заверши 2–3 вариантами следующего действия и одним связанным «Термином дня».
