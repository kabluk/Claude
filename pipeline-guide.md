## ФАЗА 0 — Prompt Engineering (1-2 часа)

### Зачем 2 часа перед кодом?

Каждый час чёткого промтинжиниринга экономит 10 часов переделок. Если ты не можешь объяснить продукт незнакомому человеку за 30 секунд — ты ещё не готов к VIBECODE.

### Шаблон идеи-промта

```
Продукт:         [название]
Клиент:          [кто именно, как можно точнее]
Боль:            [что болит у клиента СЕЙЧАС, без твоего продукта]
Решение:         [что делает продукт — одно предложение]
Дифференциатор:  [почему это лучше чем [конкурент]]
Монетизация:     [$X/мес, комиссия, разово]
MVP-граница:     [что НЕ входит в версию 1]
```

### Применение к Menvio

```
Продукт:         Menvio
Клиент:          Независимый ресторан (2-50 столиков), US/EU, $1M-5M выручки,
                 владелец 35-55 лет, без IT-навыков
Боль:            Бумажное меню — $300 в печать, медленно обновлять.
                 Конкуренты берут $150+/мес за то же самое.
                 В EU — закон требует маркировать 14 аллергенов, штраф €20k.
Решение:         Красивое QR-меню за 48 часов, $29-99/мес, мы делаем всё сами.
Дифференциатор:  AI-фото блюд + EU allergen compliance + WhatsApp-заказы без комиссии
Монетизация:     SaaS $29/$69/$99 мес + NFC-карточки $25 разово
MVP-граница:     Нет мобильного приложения. Нет POS-интеграции. Только HTML-меню + WA.
```

### Проверка готовности (Gate 0→1)

Промт готов когда ты можешь:
- [ ] Объяснить продукт незнакомому за 30 секунд
- [ ] Назвать имя конкретного первого клиента
- [ ] Сказать что НЕ входит в MVP (без колебаний)
- [ ] Обосновать каждую цифру в тарифах

## ФАЗА 1 — VIBECODE (Дни 1-5)

### Что такое VIBECODE

VIBECODE — AI-driven разработка: ты описываешь ЧТО нужно, AI пишет КАК.

**Инструменты:** Claude Code (этот чат), Cursor, Windsurf, Bolt.new

### Правила VIBECODE для Menvio

#### Правило 1: Один файл — один артефакт
Каждое меню = отдельный `.html` файл. Никаких фреймворков — работает с `file://` на любом устройстве.

#### Правило 2: CSS-first, JS-минимум
Tab switcher — только CSS (radio inputs + `~` combinator). JS только для корзины и WA-ссылки.

#### Правило 3: Офлайн-фото через CSS градиенты
Никаких внешних изображений — только `radial-gradient` стеки имитирующие студийную фотографию.

#### Правило 4: Промт-паттерн для новых фич
```
Добавь [фичу] в файл [файл].
Технически: [конкретное решение].
Стиль: тёмный, luxury, gold accent #c9a84c, red #c0272d.
Не ломай: [что нельзя трогать].
```

### Порядок разработки для Menvio

```
День 1:  CSS-система + цветовые токены + шрифты
День 2:  Tab switcher + структура разделов меню
День 3:  CSS Food Art (радиальные градиенты для блюд)
День 4:  WhatsApp корзина + плавающий CTA
День 5:  Dragon Garden LA — первый реальный демо
```

## ФАЗА 2 — FLOWSTATE (Дни 6-10)

### Что такое FLOWSTATE

FLOWSTATE — состояние потока при создании лендинга. Когда страница "течёт" — от боли к решению к действию.

**Инструменты:** Framer, Webflow, или чистый HTML (наш выбор — HTML, соответствует стеку Menvio)

### Структура лендинга Menvio

```
┌─────────────────────────────────────────────────────────┐
│  БЛОК 1: HERO                                           │
│  "Ваше меню в телефоне каждого гостя за 48 часов"      │
│  [Демо Dragon Garden прямо на экране]                   │
│  [Кнопка: Хочу такое меню]                             │
├─────────────────────────────────────────────────────────┤
│  БЛОК 2: БОЛЬ                                          │
│  "Бумажное меню стоит $300 в печать..."                │
│  [3 карточки боли с иконками]                          │
├─────────────────────────────────────────────────────────┤
│  БЛОК 3: РЕШЕНИЕ                                       │
│  Как работает Menvio:                                  │
│  Шаг 1: Ты заполняешь форму (5 мин)                   │
│  Шаг 2: Мы строим меню (48 часов)                      │
│  Шаг 3: QR-код готов — размещай везде                  │
├─────────────────────────────────────────────────────────┤
│  БЛОК 4: ДЕМО                                          │
│  Живой iframe с dragon-garden-menu.html                │
├─────────────────────────────────────────────────────────┤
│  БЛОК 5: ФИЧИ                                          │
│  6 ключевых преимуществ                                │
├─────────────────────────────────────────────────────────┤
│  БЛОК 6: ТАРИФЫ                                        │
│  Starter $29 / Pro $69 / Concierge $99                 │
├─────────────────────────────────────────────────────────┤
│  БЛОК 7: СОЦДОКАЗАТЕЛЬСТВО                             │
│  Dragon Garden LA (первый кейс)                        │
├─────────────────────────────────────────────────────────┤
│  БЛОК 8: CTA                                           │
│  Форма: имя + ресторан + телефон                       │
└─────────────────────────────────────────────────────────┘
```

### Правила FLOWSTATE

1. **Каждый блок решает одну задачу.** Боль → узнал себя. Решение → понял как. Тарифы → решил сколько.
2. **CTA на каждом экране.** Посетитель не должен скроллить за кнопкой.
3. **Демо — лучший аргумент.** Iframe с реальным меню продаёт лучше любого текста.
4. **Форма максимально простая.** Имя + ресторан + телефон. Больше ничего.

### Проверка готовности (Gate 2→Продажи)

Лендинг готов когда:
- [ ] Есть рабочая форма заявок (Tally.so или mailto)
- [ ] Ты готов ответить в течение 4 часов
- [ ] Демо загружается без ошибок в iframe
- [ ] Страница адаптивна на мобильном

## Полная связка — никогда не застрянешь

### Правила перехода

| Переход | Условие | Признак застревания |
|---|---|---|
| 0→1 | 30-секундный питч любому человеку | Объясняешь больше 2 минут |
| 1→2 | Один живой демо на реальном устройстве | Нет ни одного клиента который это видел |
| 2→Продажи | Форма заявок + ты online 4ч/день | Нет формы или не отвечаешь |

### Если застрял — диагностика

```
Застрял в Фазе 0?
→ Позвони одному реальному ресторатору прямо сейчас
→ Спроси: "Что тебя бесит в текущем меню?"
→ Заполни шаблон его словами

Застрял в Фазе 1?
→ Открой dragon-garden-menu.html
→ Сделай ОДНО конкретное изменение (не переписывай всё)
→ Используй промт-паттерн: "Добавь [X]. Не ломай [Y]."

Застрял в Фазе 2?
→ Скопируй структуру лендинга дословно
→ Замени только текст под Menvio
→ Iframe с демо — это уже 80% работы
```
