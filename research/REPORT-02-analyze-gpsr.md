# /analyze — EU Authorized Representative / GPSR Responsible Person (2026-08-04)

Вердикт: **🟢 HIGH PRIORITY, 7.1/10** (понижено с 8.4 после живой проверки SERP).

## Главное

- «Пустого SERP» больше нет: **cruxi.ai** (сеть 40+ регуляторных каталогов с RFQ-движком, есть GPSR-страница) + псевдо-сравнения провайдеров (responsible.eldris.ai, eugpsr.eu). Но интерактивного каталога **для e-commerce-селлеров** (Etsy/Amazon/Shopify) с открытыми ценами и фильтром по категории товара — нет.
- Цены услуг: GPSR RP **€195–800/год** (до €5,000 премиум), MDR EC-REP дороже. LTV клиента провайдера €600–2,000.
- Узкое место: «денежных» сущностей всего **30–80 провайдеров**. Порог 500+ добирается реестровым слоем: **EUDAMED — публичный JSON API + bulk-XML** (подтверждено), NANDO мигрировал в SMCS (публичный поиск). Из реестров строятся тысячи lookup-страниц (проверка номера notified body, SRN).
- Спрос (позже замерен DataForSEO, см. volumes-gpsr-us/uk.json): US ~2,820/мес по кластеру 46 ключей, UK ~3,210; «eu authorised representative» 140/мес @ **$48.80** (US). Микро-ниша по объёму, но очень дорогой трафик.
- Пик спроса был вокруг вступления GPSR (дек. 2024); остаточный объём — новые селлеры + churn. Мониторить.

## AI-защищённость: 5/10

Информационный слой не защищён; защищают только живые цены, реестровые данные (EUDAMED/NANDO), quote-механика, lookup по номерам.

## Решение
