Kitchen Display Setup

Connect to Supabase to receive orders in real time. Takes 5 minutes.

Step 1 — Create Supabase project

Go to supabase.com → New Project → Free tier → copy your URL and anon key.

Step 2 — Create orders table

In Supabase → SQL Editor → run this:

CREATE TABLE orders ( id UUID DEFAULT gen_random_uuid() PRIMARY KEY, created_at TIMESTAMPTZ DEFAULT NOW(), restaurant_id TEXT DEFAULT 'dragon-garden', table_num TEXT, items JSONB, total NUMERIC(10,2), status TEXT DEFAULT 'new' CHECK (status IN ('new','cooking','done')), status_updated_at TIMESTAMPTZ DEFAULT NOW() ); ALTER TABLE orders ENABLE ROW LEVEL SECURITY; CREATE POLICY "anon_all" ON orders FOR ALL USING (true) WITH CHECK (true);
