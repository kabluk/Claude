## Что уже сделано

- **Каркас приложения** (React + Vite + React Router): 6 экранов со сквозным
  прогрессом «Шаг X из 6», постоянный дисклеймер. Дизайн в стиле law-firm.
- **Мультиязычность (i18n)** — EN/ES/RU/ZH/VI, селектор в шапке, localStorage,
  по умолчанию English. Формы подаются на английском (сноска на каждом экране).
- **Хранение данных** (localStorage): User / Case / Answer / Payment; autosave
  визарда; финансовый профиль дела.
- **Визард** под сценарий «Развод по согласию, есть дети, Los Angeles»: секции
  Стороны / Дети (+ история проживания 5 лет) / Имущество / Доходы / Согласие /
  Проверка; «?»-подсказки с примерами; адрес заявителя — структурно
  (`party_street/city/state/zip/phone/email`).
- **Калькулятор child support** по формуле California §4055 + дисклеймер.
- **PDF-движок** (`src/pdf/`, pdf-lib): заполнение реальных AcroForm-полей
  (не рисование по координатам), маппинг `field_key → имя поля`, водяной знак
  «DRAFT — проверьте перед подачей», merge, `fontSizes`/`rectAdjust`.
- **Реальные формы**: FL-100 (Petition), FL-105 (UCCJEA), FL-110 (Summons) —
  официальные PDF в `public/forms/`, маппинг, demo + read-back. Пакет: FL-100 +
  FL-110 всегда, FL-105 при детях. Кнопка генерации — в личном кабинете.
- **Проверка ревизий**: `npm run check-forms` (сверка SHA-256 с courts.ca.gov).
- **SEO county-страницы** `/california/:county` (Trust-Calm Modern, EN/ES,
  title/meta/JSON-LD) из единого `src/data/counties.js`. Los Angeles заполнен,
  4 округа — заглушки (`stub: true`).
