# CarrierRadar — снапшоттер данных FMCSA

Исторический слой — главный накапливаемый актив проекта: FMCSA публикует
только текущее состояние реестра, а история изменений (мигание authority,
разрывы страховки, смены адресов — отпечатки фрода) существует только у того,
кто снимает срезы каждый день. Этот модуль снимает их.

## Источники (все — официальные открытые данные DOT)

| id | Датасет | Что это |
|---|---|---|
| `census` | az4n-8mr2 | Company Census File: 147 колонок — контакты, офицеры, парк, `prior_revoke_flag`. Обновляется ~ежедневно |
| `authority-history` | u4i8-4m26 | Carrier — All With History (L&I): файл ~500MB, история authority/страховых требований |
| `authority-current` | 6eyk-hxee | Табличная версия статусов authority (common/contract/broker, pending/revoked) |
| `sms-census` | kjg3-diqy | Месячный CSA-прогон SMS |

Юридика: программа открытых данных DOT прямо разрешает публичное
использование; произведения правительства США — общественное достояние.
Разбор ограничений (FCRA, TCPA, деривативные скоры) — репозиторий kabluk/Claude, `docs/moat-analysis.html` (+ D-005 в `docs/project/DECISIONS.md` здесь).

## Команды

```bash
node scripts/snapshot.mjs               # снять все источники за сегодня
node scripts/snapshot.mjs --only census # выборочно
node scripts/summarize.mjs [дата]       # компактная сводка Census → data/summaries/
```

## Хранение

- `data/raw/<дата>/*.csv.gz` — сырые снимки, **в git не попадают** (см. .gitignore).
  В проде уходят в release-ассеты (см. `.github/workflows/fmcsa-snapshot.yml`)
  или в объектное хранилище (R2/S3).
- `data/manifests/<дата>.json` — коммитится: URL, размеры, число строк,
  sha256 каждого файла. Происхождение каждого снимка доказуемо.
- `data/summaries/<дата>.json` — коммитится: агрегаты Census (статусы, штаты,
  типы операций, prior_revoke, парк, годы регистрации) — дельты между днями
  видны прямо в git-диффе.

## Автоматизация

`.github/workflows/fmcsa-snapshot.yml` — ежедневный прогон в GitHub Actions:
raw-файлы → release-ассеты с тегом `fmcsa-YYYY-MM-DD`, манифест и сводка —
коммитом в ветку. Серверов не требуется.
