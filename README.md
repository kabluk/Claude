# AccessAtlas

**Каталог агентств аудита цифровой доступности** — EAA / WCAG / ADA / BFSG / RGAA.
Найти проверенного исполнителя по стране × стандарту × услуге, с доказуемым источником для каждой записи.

> Отдельный проект. Живёт в ветке `accessatlas` репозитория `kabluk/Claude`
> (в `main` — другой проект, detnav; они не связаны). При желании выносится
> в собственный репозиторий одним движением.

## Зачем это

Спрос на аудит доступности замерен по 8 рынкам (DataForSEO): **≈45 000 запросов/мес**,
CPC до $86. При этом в топ-10 поиска нет ни одного каталога — только сами вендоры.
Ниша оценена в 7.9/10. Полное обоснование, архитектура и 30-дневный план:
[`docs/deepdive-accessibility-directory.md`](docs/deepdive-accessibility-directory.md).

Уникальное преимущество данных — **99 агентств, названных аудиторами в обязательных
декларациях доступности госсайтов ЕС** (Франция, Польша, Нидерланды, Германия…).
Их нет ни в одном конкурирующем каталоге, потому что имена спрятаны внутри
юридических документов и PDF-отчётов.

## Что внутри

- **254 агентства**, 21 страна. Каждая запись несёт ≥1 источник и дату проверки.
  Ничего не выдумано: неизвестное поле остаётся пустым.
- **12 редакционных гайдов** (BFSG, Section 508, VPAT, EAA, RGAA, audyt WCAG…)
  с фактчекингом по первоисточникам.
- **378 статических страниц** (Vite-SSG): профили, страны-хабы, комбо страна×услуга,
  услуги, стандарты, гайды. JSON-LD, клиентские фильтры, порог индексации ≥3.

## Технологии

Static-first: React + Vite + `vite-react-ssg` + Tailwind. Никакой БД для чтения —
источник истины плоские JSON в `data/a11y/`, страницы генерируются при сборке.

## Команды

```bash
npm install            # зависимости
npm run dev            # дев-сервер
npm run build          # данные → 378 страниц → sitemap (в dist/)
npm run build:data     # только валидация данных + индексы
npm run merge          # слить партии сборщиков (data/a11y/collect/*.json)
npm run enrich         # применить патчи обогащения (data/a11y/enrich/*.json)
npm run typecheck      # tsc --noEmit
```

## Структура

```
src/                   приложение (страницы, компоненты, lib)
data/a11y/             ДАННЫЕ — источник истины
  agencies.json          254 агентства
  taxonomies.json        услуги, стандарты, страны с законами
  types.ts               схема
  guides/*.md            12 гайдов
  collect/*.json         сырьё сборщиков (аудит-след)
  enrich/*.json          патчи обогащения
  excluded.json          «надгробия» удалённых записей
scripts/               build / merge / enrich / sitemap / seo-data
docs/deepdive-*.md      обоснование ниши и план
research/              замеры спроса и SERP
```
