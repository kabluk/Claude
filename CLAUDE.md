# CarrierRadar — память репозитория

Проект ведётся дисциплиной /project-orchestrator (.claude/commands/).
Точка входа новой сессии: docs/project/HANDOFF.md, затем STATUS/DECISIONS/BACKLOG.

Правила:
- На стратегических развилках предлагать три варианта с компромиссами.
- Юридические рамки D-005 (docs/project/DECISIONS.md) обязательны.
- Данные только уровня компаний; никаких историй водителей.
- Имя/домен централизованы константой; не хардкодить по файлам.
