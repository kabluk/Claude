# Память проекта

## Постоянное правило: варианты на развилках

Когда встаёт вопрос «что делать дальше» на уровне стратегии/приоритетов
(не мелкий тактический шаг) — **всегда предлагай три варианта** с
компромиссами по каждому, а не один путь. Формат: коротко назвать три
пути, для каждого — что выигрываем/чем платим, и дать рекомендацию с
обоснованием, но окончательный выбор оставить пользователю.

## Что это за репозиторий

Рабочее пространство для поиска и валидации SaaS/pSEO-идей (методология —
DataForSEO + живая проверка выдачи + правило «сырые данные vs готовый
реестр», см. `docs/`) и последующей разработки MVP. Одновременно здесь же
живёт исходный проект detnav (`src/`, `content/`, `data/`) — отдельный,
не путать с новыми инициативами.

Три активные линии по состоянию на 15.08.2026 — полный расклад и три
стратегических варианта развития в `docs/roadmap.html`. Перед началом
новой сессии по любой из линий — сверяться с этим файлом, он приоритетнее
пересказа в чате.
