# Память проекта

## Постоянное правило: варианты на развилках

Когда встаёт вопрос «что делать дальше» на уровне стратегии/приоритетов
(не мелкий тактический шаг) — **всегда предлагай три варианта** с
компромиссами по каждому, а не один путь. Формат: коротко назвать три
пути, для каждого — что выигрываем/чем платим, и дать рекомендацию с
обоснованием, но окончательный выбор оставить пользователю.

## Что это за репозиторий

Рабочее пространство для поиска и валидации SaaS/pSEO-идей (методология —
DataForSEO + живая проверка выдачи + правило «сырые данные vs готовый
реестр», см. `docs/`) и последующей разработки MVP. Одновременно здесь же
живёт исходный проект detnav (`src/`, `content/`, `data/`) — отдельный,
не путать с новыми инициативами.

Три активные линии по состоянию на 15.08.2026 — полный расклад и три
стратегических варианта развития в `docs/roadmap.html`. Перед началом
новой сессии по любой из линий — сверяться с этим файлом, он приоритетнее
пересказа в чате.

## Имя сессии = имя проекта + номер по порядку

Каждая сессия называется по проекту, над которым идёт работа, с номером:
«CarrierTruth — сессия 1», «CarrierTruth — сессия 2» и так далее. Номер
сплошной по проекту, не по дате. Переименование делается сразу в начале
работы (инструмент `set_session_title`), а не в конце: если сессия
оборвётся, она всё равно останется опознаваемой в списке.

При передаче в новую сессию — в промпте указывать её номер, чтобы порядок
не терялся.

## Каждая сессия по проекту начинается с оркестратора

Первым делом в новой сессии — вызвать `/project-orchestrator` и дальше
вести работу его дисциплиной (память в `docs/project/`, роли-агенты,
решения в DECISIONS, очередь в BACKLOG).

ВАЖНО, чтобы это работало: скилл лежит в `.claude/commands/` репозитория
проекта (для CarrierTruth — `kabluk/carriertruth`, бывший carrierradar),
а не в этом рабочем пространстве. Если сессия открыта не на репозитории
проекта, команда `/project-orchestrator` просто не появится в списке
доступных. Поэтому новую сессию по проекту открывать НА ЕГО репозитории.
